# Secret Santa Web Companion

This is a lightweight, responsive web version of **Secret Santa (VCN Official App)** built specifically so that friends with iPhones or computers can join rooms, propose restaurants, and vote directly from their web browser (Safari, Chrome, etc.), fully synchronized in real-time via Firebase Firestore.

## How to Run / Share

1. **Locally**: Open `index.html` directly in any web browser.
2. **Host for Free**:
   - **Firebase Hosting**: Run `firebase deploy` if configured.
   - **GitHub Pages**: Push this `web/` folder to a GitHub repository and enable GitHub Pages.
   - **Vercel / Netlify**: Drag and drop the `web/` folder to deploy instantly.
